# ADR-007 — Deterministic automation before generative AI

**Status:** Accepted

Core smart behavior must work offline and without model/API cost. Geometry, color math, font analysis, audits, templates and Do/Don't transformations are deterministic.

Optional local AI may later assist with copy, translation or classification only behind an explicit experimental feature that downloads models on demand. Generated guidance is labeled as suggested and never becomes an authoritative brand rule without user confirmation.
